FAQ

Common questions

Do you need access to our production system?

No. The pipeline's bot user is scoped to your DEV system only, and all changes move forward through your standard SAP transport process. See the security overview for the full architecture.

What SAP work fits Tier 2 best?

Reports, approval workflows, value helps, custom fields, and Fiori apps over existing data — the classic customization backlog. Complex cross-module redesigns still start with a human-led design conversation.

Do we keep the code and pipeline if we stop?

Yes. The source code lives in your GitHub org and your SAP system from day one. If the engagement ends, everything that shipped stays exactly where it is — yours.

How is this different from hiring an SI?

SIs scale with billable bodies; we scale with a pipeline. You get senior-only engineers orchestrating AI workers, mid-market pricing tied to outcomes, and a delivery system your team keeps — not a bench you rent.

What does the pilot cost?

The two-week pilot is a scoped fixed fee sized to your landscape and the backlog item we pick together. We'll quote it on the fit call.
