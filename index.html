The Cleverpath delivery pipeline
Claude Code AI worker Codex AI worker

How delivery flows: a functional user opens a GitHub issue; the Cleverpath orchestrator creates a branch and dispatches an AI worker; the AI worker generates code, tests, and artifacts; a senior engineer reviews the pull request; on merge the code is pulled into SAP via abapGit and a transport is created; the change is deployed to DEV through standard SAP transports.

  7. PR + Review
